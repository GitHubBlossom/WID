Getting Started

WhatIDid.ai is an intelligent productivity tool that automatically analyzes your Gmail, Google Calendar, and Google Drive activity to generate insightful weekly summaries powered by AI.

Prerequisites

  • A Google account (Gmail, Calendar, Drive)
  • An Anthropic API key (get one at console.anthropic.com)
  • Python 3.8 or higher (if self-hosting)

Setup Guide

Step 1: Google API Setup

  1. Go to Google Cloud Console
  2. Create a new project or select an existing one
  3. Enable the following APIs:
    • Gmail API
    • Google Calendar API
    • Google Drive API
  4. Create OAuth 2.0 credentials:
    • Navigate to "Credentials" → "Create Credentials" → "OAuth client ID"
    • Choose "Desktop app" as the application type
    • Download the credentials file
  5. Save the credentials file as credentials.json in the project directory

💡 Tip: WhatIDid.ai only requests read-only access to your data. Your information stays private and secure.

Step 2: Anthropic API Key

  1. Visit Anthropic Console
  2. Create an account or sign in
  3. Generate a new API key
  4. Copy the API key (it starts with sk-ant-)

Step 3: Configuration

Add your Anthropic API key in the Settings page:

  1. Launch the dashboard
  2. Go to Settings
  3. Enter your API key in the .env file: 
    ANTHROPIC_API_KEY=sk-ant-your_api_key_here
  4. Configure your preferences:
    • Timezone
    • Weekly summary schedule
    • Lookback period (default: 1 day)

Features

Email Analysis

WhatIDid.ai analyzes your Gmail activity to provide insights on:

  • Number of emails sent and received
  • Top contacts you communicated with
  • Email subject patterns and themes

Calendar Insights

Get a clear picture of your meeting patterns:

  • Total events and meetings attended
  • Time spent in meetings
  • Meeting attendees and collaboration patterns

Document Tracking

Monitor your Google Drive activity:

  • Documents created and modified
  • Types of files worked on (Docs, Sheets, Slides)
  • Recent document activity

AI-Powered Summaries

Claude AI generates intelligent summaries that include:

  • Executive summary of your week
  • Key meetings and collaborations
  • Main projects and focus areas
  • Actionable insights and recommendations

Using WhatIDid.ai

Manual Summaries

Generate summaries on-demand from the dashboard:

  1. Click "Run Analysis Now" for the default period
  2. Or enter a custom number of days to analyze
  3. View your summary immediately

Automated Summaries

Configure automatic weekly summaries:

  1. Go to Settings
  2. Choose your preferred day and time
  3. Enable automatic email delivery (optional)
  4. Save your settings

Viewing History

Access all past summaries from the dashboard. Summaries are organized by calendar week for easy navigation.

Frequently Asked Questions

Is my data secure?

Yes! WhatIDid.ai only requests read-only access to your Google services. All credentials are stored locally, and only summary data (not full email or document content) is sent to Anthropic's AI for analysis.

What does it cost?

WhatIDid.ai is free to use. You only need to provide your own Anthropic API key, which has generous free tier usage.

Can I customize the analysis period?

Yes! You can analyze any period from 1 to 30 days. The default is set to analyze yesterday's activity.

How do I disconnect my Google account?

Simply delete the token.json file from the application directory to revoke access.
